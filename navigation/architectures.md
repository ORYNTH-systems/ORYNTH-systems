# ORYNTH Architectures

This page provides a readable map before entering the implementation repositories.

## Unified Agency Architecture

UAA defines constitutional authority, agency, admissibility, delegation, and bounded execution.

- [UAA Core Repository](https://github.com/ORYNTH-systems/uaa-core)
- [UAA Architectural Record](https://doi.org/10.5281/zenodo.20820868)

## Execution Integrity Protocol

EIP governs runtime integrity and verifies that execution remains within established authority and control boundaries.

- [EIP Protocol Repository](https://github.com/ORYNTH-systems/eip-protocol)
- [EIP Architectural Record](https://doi.org/10.5281/zenodo.20818943)

## Adaptive Orchestration Management System

AOMS addresses bounded orchestration and adaptive coordination. Its continued formalization remains in progress.

## Constraint-Integrated Glyphic Control System

CIGCS provides constraint encoding, glyphic control semantics, and reference implementation surfaces.

- [CIGCS Reference Lab](https://github.com/ORYNTH-systems/cigcs-reference-lab)
- [CIGCS Constitutional Paper](https://github.com/ORYNTH-systems/cigcs-constitutional-paper)
- [CIGCS Architectural Record](https://doi.org/10.5281/zenodo.21080108)

## Proof of Block

Proof of Block provides verifiable evidence that required constraints and execution boundaries were satisfied.

- [Proof of Block Repository](https://github.com/ORYNTH-systems/proof-of-block)
- [Proof of Block Record](https://doi.org/10.5281/zenodo.20821319)
